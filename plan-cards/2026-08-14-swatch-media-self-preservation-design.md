## 결정 골격 (6개)

- **swatch_media 엔티티**: object_key(버킷명 비포함)+메타가 정본, image_urls는 전환기 폴백. 상태 4종 + 재시도 메타. 영구 유실 = swatch 행 삭제(개정 1).
- **대표사진 관계화**: shade_images URL 문자열 복사 → media_id FK. #513의 URL 매칭 회수(P3-18)가 관계 기반으로 교체됨.
- **어댑터 일원화**: 프론트 URL 조립 한 곳 + 서버 복사 함수(service role). 클라이언트 스토리지 직접 쓰기 폐지. S3 이식 경계.
- **등록 자동 복사**: 등록 즉시 완료, 직후 서버 복사. 실패는 pending+재시도 — 등록을 안 막는다.
- **이중 버킷 수명주기**: 공개=public URL, 숨김=private 이동+소유자 서명 URL, 삭제=제거. DB 트리거는 스토리지 직접 조작 금지 — outbox 큐를 서버가 공식 API로 소비(#513 비공식 SQL 삭제 폐기). 잔존 노출 창 = CDN TTL+소비 지연, 문서화된 경계.
- **백필·GC·정책**: 콜드 백업 176장 승격, 고아 210 GC 삭제, 버킷 INSERT 무스코프 폐쇄.
