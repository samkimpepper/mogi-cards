## 전편 설계 카드에서 바뀐 것 (결정 3건, 전부 모기 확정)

- **§1 인용 자격**: "원작자 OR 등록자" → **검증 확정 원작자 본인만** + **자기등록 예외**(2026-08-14 부록 A — 본인 등록 + 타인 핸들 표기 없음이면 미검증도 인용 가능). 대리등록 미검증 행은 누구도 인용 불가.
- **§3 전면 개정**: "요청 동선 용도 축소" → **RESTRICT 제거 + 원작자 삭제 무조건 통과 + removal 계열 통째 폐기** (RPC 3종·컬럼·인덱스·어드민 큐·앱 호출부까지 — 체인 실측에서 폐기 대상이 결정문 명시 목록보다 넓게 나옴). 삭제 = 즉시 공개 종료, 내부 정리는 원자적 + 실패 폐쇄.
- **레인 분할**: A = 마이그 전체 + 죽은 소비처 제거(dev 초록 유지 목적) / B = 신규 UI(버튼·토글·삭제 UX·자리표시), A 머지 후. B는 미리보기 게이트 대상.
