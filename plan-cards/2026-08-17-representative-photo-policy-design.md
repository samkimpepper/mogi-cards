# 카드 — 공용 대표사진 정책 재결정: 설계 확정 (sw-u4r B레인 선행 게이트)

작성: 집냥이(home seat), 2026-08-17. 현재 상태: **초판 모기 승인 완료 → 과외 세션 재검토 대기.** 이 재검토가 이 카드의 존재 이유다 — 모기가 "과외냥이랑 같이 다시 검토"를 명시 조건으로 승인했다(2026-08-17). **B레인 발사 = 과외 검토 반영 + 모기 재확인 후.** A레인 PR #518은 머지·원격 적용까지 완료된 상태(2026-08-16 적용 창), 출시는 1~2주 연기 중(기니피그 회복기).

## 무엇을 왜 재결정했나

원작자 직접권(#513·#518)으로 사진 주인이 발색을 직접 숨김·삭제할 수 있게 됐는데, 공용 탐색의 shade 대표사진 규칙(D-099)은 first-come 고정 + **회수 후 재선정 규칙이 없다**. 그대로 두면 사진 있던 자리가 이유 없이 색상칩으로 퇴행하고 안 돌아온다. FK 구조화(A레인)만 하면 이 불안정 정책이 고착된다는 과외 적중이 이 게이트를 만들었다.

## 결정 골격 (4개)

- **사다리 유지 + 끝단 보강**: 어드민 단독 > 자동 단독 > 비교 fallback(라벨) > 색상칩 > **중립 회색칩(hex 없음, 신설)**. 팔레트 예외(D-100) 유지. "탐색 노출 자격에 이미지·색상 유무를 쓰지 않는다"(자체 보존 결정문 개정 2)가 예외 없이 완성된다.
- **회수 시 자동 재선정 (본체)**: 대표사진의 원본 발색이 숨김·삭제되면 회수와 같은 작업 단위에서 남은 후보 중 자동 선정. 후보 = 그 색을 매핑한 타 발색들의 **첫 사진**(사진별 매핑 신설 없음). 등급 우선, 동급 first-come. 숨김·삭제 동일 취급, **숨김 해제는 대표 비복원**(어드민 예외 수정만).
- **구조 연결**: shade_images URL 문자열 → media_id FK(A레인 확정 소비, P3-18 해소) 위에 재선정을 얹는다. 홈 화면 계약(내 발색샷 우선, D-118·§7)은 불변 — 공용 탐색과 다른 화면 계약 분리 유지.
- **무색상 27개**: 회색칩 + 이름으로 한시 노출, 출시 DB 큐레이션(sw-jqv)에 hex 채우기/삭제 판정 편입.

## 과외 검토 요청 포인트 (백지 재검토 환영, 특히 여기)

- **재선정의 원자성**: "회수와 같은 작업 단위"가 B레인 구현에서 outbox 소비와 어떻게 맞물려야 하나 — 회수는 큐 소비(비동기)인데 재선정을 어디에 붙여야 반쪽 상태(대표 없음 창)가 안 생기나.
- **숨김 해제 비복원**의 사용자 감각 — 자기 사진이 대표였다가 숨김 토글 한 번에 영구히 자리를 잃는 게 원작자 관점에서 수용 가능한가.
- **첫 사진 고정의 오대표 위험** — 재선정으로 뽑힌 타 발색 첫 사진이 비교 단체샷일 때 라벨만으로 충분한가 (D-099 원래 트레이드오프의 재선정 국면 재적용).
- 27개 회색칩이 탐색 카드 그리드에서 시각적으로 죽은 칸처럼 보이지 않는지 (B레인 화면 계약 재료).

## 이해 체크 골격 (과외냥이용 — 주관식 재료)

- 회수 후 재선정이 없으면 어떤 화면 퇴행이 일어나는가 (first-come 고정의 사각)
- 숨김과 삭제를 대표 회수에서 동일 취급하는 근거 (#513 경계)
- 사진별 매핑을 신설하지 않고도 재선정이 가능한 이유와 그 대가
- 홈 fallback과 공용 탐색 대표가 왜 다른 화면 계약이어야 하는가
