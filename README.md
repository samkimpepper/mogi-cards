# mogi-cards — 모기의 이해부채 공책

이 저장소는 **모기 개인의 학습·승인 보조 공책**이다 (비공개). swatch 제품 저장소가 아니고, 여기 있는 문서는 제품의 SSOT가 아니다 — 원문(PR·결정 문서)을 읽으러 가는 길잡이다.

## 여기서 새 세션(코덱스 등)을 열었다면

네 역할은 십중팔구 **과외 세션**이다. [0-guide-tutor-preamble.md](./0-guide-tutor-preamble.md)를 읽고 그 역할대로 시작하라. 모기가 재료(카드·PR·체크아웃 경로)를 주지 않았다면 "이번 재료 뭐야?"라고 물어라. 제품 저장소는 읽기 전용이고, 이 저장소(mogi-cards)에만 쓸 수 있다.

## 파일 종류

| 접두사 | 무엇 | 누가 쓰나 |
|---|---|---|
| `0-guide-*` | 운영 가이드 (카드 작성법·이해 체크·과외 프리앰블) | 사람/마스터가 유지 |
| `1-card-<날짜>-<주제>.md` | **리드 카드** — PR·계획을 모기가 승인 판단할 수 있게 10~20줄로 줄인 것. 5절 구조: ①반드시 읽을 결정 ②모기가 결정할 것 ③위험한 가정 ④증명된 증거 ⑤안 읽어도 되는 세부 | swatch 마스터(냐옹이)가 READY PR마다 배달 |
| `1-card-*-해설.md` | 카드에 대한 문답 증류 — 과외 세션에서 나온 질문·답 기록 | 과외 세션이 쓰고 모기가 승인 |
| 카드 안 `## 모기 메모` / `> 메모:` | 모기의 공부 메모 — 카드 원문과 구분해 붙인다 | 모기 또는 과외 세션 |

## 흐름 (누가 뭘 하나)

1. swatch 워크스페이스의 워커가 PR을 만들면, **마스터(냐옹이)가 카드를 여기 배달**한다.
2. 모기는 카드를 읽고 — 더 파고 싶으면 **과외 세션**을 열어 카드·PR을 재료로 질문한다.
3. 과외 중 나온 좋은 문답은 해설 파일로, 발견물(버그 의심 등)은 "마스터 전달용 메모"로 모기를 거쳐 마스터에게 간다. 과외 세션은 제품 코드를 절대 고치지 않는다.
4. **PR 머지는 항상 모기가 직접** 한다.

## 경계 (어기면 안 되는 것)

- swatch 제품 저장소(swatch-v2)에는 이 저장소를 가리키는 포인터를 만들지 않는다 (person-agnostic 원칙, PR #305 교훈).
- 이 저장소는 비공개다. 카드에 제품 내부 정보는 괜찮지만, 여기 내용이 공개 표면(PR 코멘트 등)으로 역유출되면 안 된다.
- 토큰·키·비밀값은 여기에도 쓰지 않는다.
