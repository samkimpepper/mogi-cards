# mogi-cards 과외 하네스

이 디렉터리는 `swatch-v2`에 들어갈 제품 설계가 아니라, 모기의 과외 세션을 어떻게 부트하고 운영하고 관찰할지에 관한 도구 중립 문서를 둔다.

## 디렉터리 역할

- `pilots/`: 아직 영구 규칙이 아닌 한시 실험. 각 문서가 실행 횟수·중단 조건·승격 금지를 직접 적는다.
- 이후 실제 필요가 생길 때만 `guides/` 같은 하위 디렉터리를 추가한다. 빈 분류를 미리 만들지 않는다.

모기가 테스트 요청 프롬프트를 다시 쓰고 싶을 때는 [실패상황 테스트 요청 파일럿](./pilots/2026-10-19-invalid-input-and-broken-tool-tests.md)의 두 종류 표와 복사용 프롬프트를 참고한다. 세션 부트에 자동 적용하는 규칙은 아니다.

[필요한 설명 깊이 선택 파일럿](./pilots/2026-10-20-explanation-depth-and-jargon.md)은 다음 자연 발생 PR·리뷰 설명 3건에 한시 적용한다. 사용자 말로 풀기·실제 코드 몇 줄·순서/상태 설명 중 필요한 첫 깊이를 과외냥이가 고르고 실제 사용감을 기록한다. SessionStart가 읽는 프리앰블에 상태·횟수 확인 경로를 두었으며, 3건 뒤 자동 적용을 멈추고 모기와 유지·수정·폐기를 정한다.

[커밋 메시지와 변경 전후 그림 파일럿](./pilots/2026-10-22-commit-change-scenes.md)은 여러 의미 있는 커밋에 걸쳐 바뀌는 PR 한 건에서 핵심 변경을 순서대로 본다. 커밋 링크·메시지와 터미널용 글자 그림을 함께 보여주고 사용감을 기록한 뒤 멈춘다. 기존 `due --event review` 조회로 발견하며, 모든 PR에 적용하거나 전체 구현 궤적 재생 도구를 만드는 절차는 아니다.

## 현재 경계

- 2026-10-18 모기의 명시적 요청으로 과외 하네스 개발·개선과 파일럿의 동결을 해제했다. [현재 운영 상태](../README.md#현재-운영-상태--2026-10-18-재개)에 따라 필요한 작업을 진행하며, 파일럿별 적용·중단 조건은 유지한다.
- 루트의 `AGENTS.md`는 세션 부트 정본으로 유지한다.
- 루트의 `guide-tutor-preamble.md`와 `guide-mogi-head-test.md`도 현재 SessionStart 훅이 직접 읽으므로 이번 파일럿 때문에 옮기지 않는다.
- `.codex/`는 Codex 전용 훅 구현, `harness/`는 도구 중립 운영 원문이라는 경계를 둔다.
- `pr-cards/`·`plan-cards/`·`code-diff-notes/`의 활성 재료 목록에 `harness/` 문서를 섞지 않는다.

## 파일럿 승격

파일럿은 정해진 실행 수에 도달해도 자동으로 영구 규칙이 되지 않는다. 실행 기록을 모기와 다시 보고 유지·수정·폐기 중 하나를 정한 뒤, 필요한 경우에만 루트 가이드와 부트 문서를 별도 변경한다.
