## fix1이 고치는 것 (교차 리뷰 확정분 — 왜 아직 머지 불가인가)

1. [높음] 핵심 화면의 공용 대표가 어댑터를 **우회**해 생 URL을 쓰고 있었다 — 서빙 전환이 사실상 미완이었던 구멍
2. [높음] 복사 진행 중에 숨기면 완료된 사본이 공개 버킷에 영구 잔류 (A레인 기적용 마이그의 잠복 결함 — 신규 마이그로만 수리)
3. [높음] 사진 교체 두 번째부터 대표 회수가 끊기는 관계 단절
4. [높음] Storage 일시 오류를 "객체 없음"으로 오판해 공개 객체 잔류 가능
5~7. [중간] 재시도 예산 굶김 · 판정 RPC 장애 시 죽은 카드 재노출(fail-open→closed) · URL 전역 매칭 오연결
8. [낮음] 복구 버튼 실패 시 재시도 불가 UX

반증 통과(안심 재료): 재선정 원자성("대표 없음" 창 없음) · 서명 URL 타인 발급 경로 없음 · private 버킷 여는 정책 0 · 범위 준수.

## fix2~fix4 요약 (라운드별 수렴 — 정본은 계약·판정 문서)

- **fix2** (5건): 개별 Storage timeout + 200 오판 본문 판정 + 빈 상태 위장 reject 전파 + 불확실 소비 재시도 상한 + URL 폴백 3규칙(발색 스코프·생존 사본·manual 자리 보존). 워커가 옛 결함을 되심어 감시선이 잡는지 음성 대조까지 수행.
- **fix3** (5건): 데드라인 관통 + 환불(총 시도 6회 유계) + maxDuration 명시 + URL 경합 직렬화 — advisory lock 단독 불충분을 실경합 하네스로 증명하고 FOR UPDATE 재계수 추가.
- **fix4** (머지 전 필수 4건): abort 환불 도달 봉합 + 총 체류 상한 계산식화 + **락 교착 2자리 폐쇄**(하네스로 fix3판 deadlock 재현 → fix4판 통과, 서버 로그 실물) + maxDuration glob 회귀 제거. 머지 후 이슈 1건 = 하네스 CI 편입(sw-rc1).

## 2026-08-18 결정 2개 (네가 정한 것)

1. **자체 사본 "채택" 경로 폐기** — 우리 버킷에 이미 있는 객체를 재사용하던 절약 기능을 없애고, 모든 사본을 우리가 `swatch/<발색id>/…`에 새로 만든다. 소유가 규칙이 아니라 **구조**가 된다. 대가: 어드민이 올린 사진은 바이트가 두 벌(원본은 고아로 남고, 고아 정리는 C레인 일감). → 지금 fix7로 진행 중. 경위: [결정 카드](../plan-cards/2026-08-18-object-key-adoption-boundary.md)
2. **어드민 shade 갤러리 업로드 경로 폐기 + 기존 갤러리 사진 전량 삭제** — 보안 필수가 아니라 제품·저작권 판단이라 **#520이 아닌 별도 레인**(트래커 sw-yvb, 머지 후). 착수 시 조사표부터 뽑는다 — `shade_images`에는 **유저 발색에서 승격된 대표 행이 섞여 있어서**, 그것까지 지우면 이번 PR의 대표사진 재선정 설계를 되돌리게 된다. 눈에 보이는 결과: 사다리의 '공용 대표' 칸이 비어 색상칩/회색칩 표시로 내려간다.
