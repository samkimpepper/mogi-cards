- 네 결정("웹 수집물 전량 제거")의 이행분: 조사표 82건(제품컷 파일 79개 + seed 61행) **전량 삭제** + 작업 중 추가 발견된 **Temptalia 크롤 데이터 341건**의 핫링크 제거·파일을 공개 서빙 경로 밖(`scripts/data/`)으로 이동. seed는 그쪽 생성 스크립트로 재생성해 재발 방지.
- **출시 사이트 화면엔 영향 없음** — 원격 DB의 대표 이미지 전부(96행)가 트위터 CDN이라 이번 제거와 무관해. 색상칩으로 바뀌는 건 **로컬 개발 환경**에서만.

## 2. 네가 결정할 것

- 머지 여부. 잔여 확인 하나: 워커 환경에 Docker가 없어 `supabase db reset` 실측을 못 했어. seed가 손 편집이 아니라 생성 스크립트 재실행 산출물이라 위험은 낮고, 네가 집 맥북(docker 가능)에서 다음 reset 때 자연 검증돼. 그래도 걸리면 머지 전에 reset 한 번 돌려보고 머지하면 돼.
