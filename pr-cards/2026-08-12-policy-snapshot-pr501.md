## 1. 반드시 읽을 결정

- **정책 스냅샷이 저장소에 산다**: `supabase/POLICY-SNAPSHOT.md` — RLS 정책 113개·anon/authenticated 권한 경계·SECURITY DEFINER 함수 26개를 표로 뜬 **실물의 사본**(의도 문서 아님, 손 수정 금지). 마이그레이션 PR의 diff가 곧 "정책이 이렇게 바뀐다" 리뷰 자료가 되고, CI가 낡음을 검출한다(다르면 빨간불).
- **사람말 요약이 PR 코멘트로 자동 게시된다** — 네가 확인해 준 그 방식("긴 표는 자동화가, 나는 한두 줄만"). 스티키 코멘트라 푸시마다 갱신되지 쌓이지 않는다. PR 템플릿의 "pg_policies 검증" 수동 절이 이걸로 자동화됨.
- **CI가 필수 체크화 가능 형태로 재구성됐다**: 트리거 경로 필터를 없애고 잡 안에서 변경 파일을 실측 — 무관 PR은 스택 없이 수십 초 통과(임시 PR로 10초 실측 후 폐기). 머지 후 branch protection 설정이 가능해진다.

## 2. 네가 결정할 것

- **머지 여부** (과외냥이 퀴즈 후, 늘 그렇듯 네 손).
- **머지 후: CI 필수 체크화** — 이제 워크플로가 모든 PR에서 결론을 내는 형태라 안전하게 걸 수 있다. 원하면 절차를 클릭 단위로 안내함.

## 3. 위험한 가정 (교차 리뷰가 잡았고 → 수리됨)

1라운드에 구멍 8개(major 7)가 있었고 전부 수리됐다. 대표 3개는 공부 가치가 있다:
- **RLS 끄기·RESTRICTIVE 전환이 스냅샷 밖이었다** → 이제 RLS 활성 상태 절 + permissive 열이 diff에 드러낸다 (수리 재현: 임시 RLS 비활성 → diff 포착 확인).
- **`GRANT TO PUBLIC`이 증발했다** → PUBLIC 전용 열 신설, anon·authenticated 실효로 붙는다는 설명 동반.
- **요약이 실효 접근을 단정했다** → "~를 허용하는 정책 추가"식 규칙 수준 서술로 전환, 상호작용 경고를 요약 머리에 고정. 스냅샷 머리말에도 "이 파일이 같다고 접근 통제가 같다고 단정하지 않는다"가 박혔다.

수리 후에도 남는 경계: 스냅샷은 **구조**다 — 실제 앱 동선 확인을 대체하지 않는다. 리터럴 내부 개행 접기의 잔여 경계는 스냅샷 머리말에 명시돼 있다.
