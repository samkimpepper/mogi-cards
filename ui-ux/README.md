# UI·UX 참고 자료실

이 폴더는 모구밍위키를 실제로 사용한 영상, 인터뷰, 화면 구조 후보를 모기의 관점에서 다시 읽기 위한 참고 자료실이다. 제품 구현의 SSOT나 네 번째 작업 대기열이 아니며, 과외 세션 시작 때 자동으로 읽지 않는다.

## 이곳에 두는 것

- 실제 사용 영상의 행동·화면 분석
- 인터뷰 질문과 관찰 기록
- 화면 구조와 사용자 동선 후보
- 분석을 다시 확인하는 데 필요한 소수의 핵심 프레임

## 다른 기록과의 경계

- `raw/`: 사용자 메시지와 과외냥이 최종 답변의 정확한 원문
- `ui-ux/`: 무엇을 보고 어떻게 판단했는지 증류한 참고 자료
- `master-delivery-memos.md`: 마스터가 제품 작업으로 라우팅할 발견물과 확정 결정
- `plan-cards/`: 실제 착수 전 설계·SPEC 학습 카드
- `../swatch-ops/reports/`: 마스터·워커가 만드는 운영 분석 보고서. 과외 세션은 쓰지 않는다.

## 기록 원칙

1. 문서 이름은 `<날짜>-<대상>-<주제>.md`로 시작한다.
2. 원본 영상은 기본적으로 Git에 넣지 않는다. 파일명, 크기, 길이, 해시와 보관 위치를 문서에 남기고 재검토에 필요한 핵심 프레임만 `assets/`에 둔다.
3. `관찰 사실 / UX 해석 / 해결안 후보 / 소유자 확정 / 미결·인터뷰 대기`를 섞지 않는다.
4. 화면만으로 의미가 모호한 조작은 필요할 때 읽기 전용 제품 코드로 확인한다. 외부 분석자의 오독도 화면이 동작 대상을 충분히 말하지 못했다는 사용성 증거가 될 수 있지만, 구현 사실처럼 옮기지는 않는다.
5. 제품 작업이 필요한 발견물은 열린 운영 이슈와 중복을 확인한 뒤 `master-delivery-memos.md`로 보낸다. 이 폴더의 문서만으로 작업을 발주하거나 우선순위를 확정하지 않는다.
6. 한 사례에서 쓴 방법을 바로 영구 가이드로 승격하지 않는다. 다른 영상·인터뷰에서도 효용이 반복 관찰되면 별도 가이드로 증류한다.
