# 머가리 테스트 러너

이 폴더의 러너는 과외냥이의 프롬프트 준수를 믿는 대신, A/B 제시 순서와 시간·피드백·지연·중단 규칙을 브라우저 코드로 잠근다. 서버나 패키지 설치 없이 로컬에서만 동작한다.

## 실행

1. `runner.html`을 브라우저로 연다. `file://`로 열어도 된다.
2. `cases/policy-snapshot-demo.json`을 선택한다.
3. 화면 순서대로 답하고, 끝이나 중단 시 `실행 JSON 저장`을 누른다.
4. 저장한 JSON을 `runs/`에 옮길지는 모기가 결정한다. 러너가 저장소에 직접 쓰지는 않는다.

PR #501 케이스는 이미 학습한 소재라 UI에도 `demo_only`로 표시된다. 조작 확인용이며 측정 결과로 쓰지 않는다.

## 코드가 강제하는 것

- canonical 규칙은 정확히 5개다.
- A/B는 같은 규칙과 질문 템플릿에 서로 다른 이름 사전만 적용한다.
- 템플릿 토큰 누락이나 A/B의 같은 라벨은 시작 전에 거부한다.
- 초기 블록에는 사실 회상·상태 추적·새 사례 추론·모순 탐지가 하나씩 있어야 한다.
- 초기 두 블록의 활성 제한시간은 8~10분이고, 지연 대기 시간은 이 제한에 포함하지 않는다.
- 첫 블록 답 네 개를 모두 잠그기 전 다음 블록으로 갈 수 없다.
- 초기 두 블록과 지연 두 블록이 모두 끝나기 전에는 expected와 채점을 공개하지 않는다.
- 요약 없는 지연 답을 먼저 잠근 뒤에만 표가 있는 지연 문제를 연다.
- `여기서 중단`은 즉시 세션을 잠그고 남은 문항을 오답이 아닌 미시행으로 기록한다.
- 입력 결함 신고는 내용을 설명받기 전에 비교를 무효화하고 세션을 잠근다.
- 원답 수정 과정, 최종 제출, 시각, 단계 전이를 JSON에 보존한다.
- 자동 채점은 expected가 있는 구조 입력의 exact match와 전후 반전만 한다. 자유서술은 항상 `manual_review`다.

기존 `guide-mogi-head-test.md`의 “20분 진행”을 그대로 구현한 것이 아니다. 이 러너의 `head-test-1.0`은 초기 A/B 활성 측정을 8~10분으로 줄이고, 지연 검사는 별도 잠금 구간으로 분리한 실험 버전이다.

## 새 카드용 케이스 만들기

1. `cases/policy-snapshot-demo.json`을 복사해 `<날짜>-<주제>.json`으로 이름을 바꾼다.
2. `id`, `title`, `description`을 바꾸고 실제 측정이면 `demo_only: false`로 둔다.
3. 처음 보는 작고 독립적인 카드에서 구조화 규칙 5개만 뽑는다.
4. 각 규칙의 `paragraph`와 `table`은 같은 사실을 표현해야 한다. 문단은 여러 문단으로 렌더되고 표는 정보 출처·값의 주인·이벤트·전후 값을 분리한다.
5. 고유명사는 `{{token}}`으로 쓰고 `variants.A`와 `variants.B`에 서로 다른 값을 넣는다.
6. `initial_questions` 네 개는 질문 종류를 하나씩 사용하고, 두 variant에 같은 추론 단계를 요구해야 한다.
7. 기계적으로 비교할 짧은 값만 `expected`로 둔다. 모순 판단과 이유는 자유서술로 받아 사람이 본다.
8. 원문에 없는 외부 지식을 정답 전제로 넣지 않았는지 별도 검토한 뒤 실행한다.

검증 명령:

```bash
node --test head-test/runner-core.test.cjs
```

## 사람이 검토해야 하는 것

소프트웨어는 아래를 타당하게 판정하지 않는다.

- 구조가 같다는 이유만으로 실제 인지 난도도 완전히 같은지
- 카드가 모기에게 정말 낯선지
- 자유서술의 의미적 정답성, 새 모순 발견, 정당한 전제 반박
- 오류 원인이 작업기억·도메인 비숙련·문서나 설명 품질 중 무엇인지
- 피로 신호가 없으니 피로도 없었다는 판단
- 한 번의 결과로 지능·인지능력·의학적 상태를 판단하는 일
- 표 뒤 성능 향상을 표의 인과효과로 확정하는 일

입력 결함·내용 설명·피로·시간 초과가 섞인 실행은 효과 판정에서 제외한다. 서로 다른 새 카드의 유효한 실행이 최소 두 번 쌓이기 전에는 잠정 결론을 갱신하지 않는다.
