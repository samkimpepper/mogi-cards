# 세션 종료 이해 관찰 — 학습 누적 검토와 인터뷰 보충 리허설

날짜: 2026-08-25

## 오늘 조건

- **도메인 친숙도:** PR·발색 기록·공개 범위의 제품 의미에는 앞선 과외 경험이 있었다.
  인터뷰에서 열린 질문과 유도 질문을 구분하고 Raw evidence와 Synthesis를 나누는 기록
  방식은 이번 보충 리허설에서 직접 연습했다.
- **세션 길이:** 정확한 wall-clock은 미측정. raw 기록 기준 사용자 메시지 36개가 이어진
  장시간 세션이며, 학습 누적 검토·과외 규칙 점검·인터뷰 보충 리허설을 차례로 진행했다.
- **모기가 명시한 컨디션:** 기록 연습 중 “흑흑 힘들다옹”, 전달 단계에서
  “아이고힘들어”라고 피로를 명시했고, 마지막에 퇴근과 세션 종료를 알렸다. 이후 생략이나
  압축은 독립 추론 실패로 세지 않는다.
- **관찰 성격:** 과거 종료 기록 4개의 누적 검토, 과외 입력 방식에 대한 회고, 가상 코덕을
  대상으로 한 `B4 → D7/D8 → F11 → G12` 리허설, Raw/Synthesis 직접 작성. 관찰 사례
  5개. 실제 인터뷰 참여자의 제품 수요·행동은 관찰하지 않았다.

## 짧은 기록

- **처음 막힌 지점:** 인터뷰 B4 첫 질문에서 `트위터/노션` 선택지를 먼저 제시했고,
  D7 뒤에는 별도 저장소가 편할 것이라는 해결책을 심었다. 기록 단계에서는 실제 발화,
  실물 관찰, 진행자의 해석을 한 문장에 섞었고 `겁나 정확하고 체계적`처럼 판단 근거를
  다시 찾기 어려운 표현을 썼다.
- **설명 추가 없이 바로 연결한 지점:** 해결책을 유도한 질문 직후 “이런 질문 하면
  안된다”고 스스로 중단하고 D8을 다시 시작했다. 공개 트윗만 등록 입구로 쓰면 애초에
  공개하기 싫어 사진첩에 둔 발색은 `나만 보기`로도 등록할 수 없다는 원본 공개와 서비스
  공개 범위의 차이를 바로 발견했다. 과외 프리앰블 규칙이 다시 늘어난 일을
  `재귀지옥`이라고 표현하고, 실제 사용 흔적이 없는 AskUserQuestion 규칙을 점검하도록
  범위를 돌렸다.
- **설명·외부화 뒤 달라진 점:** B4에서 가장 최근 트윗 실물을 요청했고, D7의 비공개
  경험·이유와 D8의 실물 기반 공개 범위·익명 통계를 분리했다. F11에서는 선택지를 말하지
  않은 채 첫 행동 `내 발색`과 검색 경로를 관찰하고 사후 이유를 받았다. Raw에는 직접
  발화·실물·행동을 두고 `정확성을 중시한다`, `등록 병목이 있다` 같은 해석은 Synthesis로
  옮기는 교정을 적용해 직접 초안을 끝까지 작성했다.
- **아직 미관찰이거나 다음에 확인할 점:** 실제 참여자 인터뷰에서 예시를 먼저 심지 않고
  열린 질문을 유지하는지, 화면 녹화·타임스탬프 전사·AI 초안 뒤 실물과 F11 첫 행동이
  정확히 보존되는지는 미관찰이다. 가상 코덕 답변은 진행 연습용이라 제품 수요나 정책
  근거로 세지 않는다. 추천 비공개 결정 브리프도 실제 실행 기록은 확인되지 않아 효용은
  미관찰이다.

## 학습 마찰·재확인·새 발견

> “이런 질문 하면 안된다옹.. D8로 넘어가겠다옹.”

해결책을 먼저 제시한 질문을 독립 증거로 쓰지 않고 해당 구간을 다시 시작했다.

> “트위터통해서만 발색등록이 가능한데 그럼.... 공개계정에 올린걸 우리사이트에 올리고
> 굳이 비공개로 바꾼다?”

공개된 원본을 서비스에서 비공개로 정리하는 동작과, 처음부터 공개하지 않은 사진을 직접
등록하는 동작이 다르다는 제품 입력 경계를 발견했다. 이 구분은 기존 질문지 C6의 직접
업로드 경로 판단에 이미 포함돼 있어 새 발견물 메모로 중복 등재하지 않았다.

> “그냥 녹화하고 내가 그대로 받아적고 ai한테 요약해달라하면안되냐옹? 흑흑 힘들다옹”

기록 부담을 명시한 뒤에도 모기가 직접 작성 연습을 끝까지 수행했다. 실전 기본값은 모든
발화를 수기로 받아쓰는 것이 아니라 동의받은 녹화·타임스탬프 전사를 Raw로 보존하고,
AI가 나눈 초안에서 직접 인용·실물·첫 행동·과잉 추론만 사람이 대조하는 방식으로 정리했다.
