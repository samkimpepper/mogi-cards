# head-test-1.0 레거시 실험 데이터

이 폴더는 기계식 A/B 러너 `head-test-1.0`에서 사용하던 데이터를 역사적 재현을 위해 보존한다.

- `cases/`: 참가자에게 제시했던 케이스 JSON
- `keys/`: 완료 뒤에만 불러오던 reviewer-only 정답 키
- `runs/`: 실행 JSON을 보관하려던 기존 위치. 실제 실행 파일의 존재를 보장하지 않는다.

이 데이터는 현행 기본 과외 자료가 아니며 자동 세션 목록에 포함하지 않는다. 새 케이스나 실행을 기본적으로 이곳에 추가하지 않는다. 러너를 명시적으로 재현할 때만 루트의 `head-test/README.md`를 따른다.
