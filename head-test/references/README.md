# 외부 참고 원문

이 폴더는 모기 과외·학습 방식에 관해 외부에서 받은 피드백과 연구자료 원문을 보존한다.

- 이곳의 문서는 채택된 과외 규칙이 아니다.
- 기본 과외 세션에서는 자동으로 읽지 않는다.
- 실제로 채택한 규칙은 `guide-mogi-head-test.md`에 짧게 반영한다.
- 실제 세션에서 관찰한 결과는 `head-test/*-session-end-analysis.md`와 `head-test/*-learning-observation-cumulative-review.md`에 남긴다.
- 외부 인용의 사실성·적용 범위는 별도로 검토하며, 원문 보존 문서 자체를 검증 완료 자료로 취급하지 않는다.
